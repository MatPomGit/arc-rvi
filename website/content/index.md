# Autonomous Robotic Visual Inspection

ARC-RVI develops hardware-independent research tools for target localization, viewpoint selection, coverage assessment and photographic quality evaluation.

**Physical robot control is not implemented.** Unitree G1 EDU is a reference platform for future, separately authorized trials. Current executable workflows use synthetic fixtures and exploratory simulations, not physical validation.

## Research programme

- [Eight prospective studies](experiments/README.md) and [shared analysis](experiments/analysis/README.md).
- [Architecture](docs/architecture.md), [simulation](docs/simulation.md) and [benchmark](docs/benchmark.md).
- [Methodology](docs/methodology.md), [reproducibility](docs/research/reproducibility.md) and [safety](docs/safety.md).
- [Scientific state](docs/project-state.md) and [software guide](project-readme.md).

The reference mission is [photographing a specified vehicle or component](docs/vehicle-inspection-missions.md), including reflective bodywork, followed by operator-confirmed handoff. The current evaluation is offline.
