# Scientific state

ARC-RVI comprises eight prospective studies and research software supporting offline visual inspection. The [study index](../experiments/README.md) describes research questions and protocol status. The [architecture](architecture.md) describes implemented software and limitations.

Current evidence is based on synthetic fixtures and exploratory simulation. Physical robot integration and field validation remain unverified. Candidate manuscripts are not completed publications. See [methodology](methodology.md), [reproducibility](reproducibility.md) and [safety](safety.md).
