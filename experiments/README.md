# Research program: eight independent studies

Each directory contains a preregistration-ready **draft protocol**, not
experimental results. Use shared code in `src/rvi`; do not copy algorithms
into paper-specific implementations.

| Study | Distinct contribution | Evidence plan |
| --- | --- | --- |
| 01 | Reproducible benchmark and task taxonomy | simulation |
| 02 | Instance-level target localization | simulation + physical |
| 03 | Whole-body-aware joint view/path planning | simulation |
| 04 | Uncertainty-aware adaptive surface coverage | simulation + physical |
| 05 | Locomotion influence on acquisition repeatability | physical + simulation |
| 06 | Closed-loop image quality and recovery | simulation + physical |
| 07 | Calibrated simulation-to-physical transfer | simulation + physical |
| 08 | Controlled end-to-end documentation assessment | physical |

The shared fixture is a software test only. Prior to collecting evidence,
freeze independent units, baseline implementation, split plan, sample-size
reasoning, failure definitions and data rights. Track overlapped results and
citation links across manuscripts; no duplicate primary analysis.
