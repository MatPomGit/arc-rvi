# World assets

`planar_inspection.json` is an original analytic test scene in metres and radians.
It uses the `planar_geometry_kinematics_v1` model. The [simulation specification](../../docs/simulation.md)
defines coordinates, area weights, visibility, motion and known limits.

Keep small original or appropriately licensed definitions here. Record geometry source
and version for future meshes. Keep private site scans outside Git.
